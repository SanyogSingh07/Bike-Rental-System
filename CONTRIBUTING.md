# Contributing

Thank you for contributing to Volt Rental.

## Workflow

1. Create a feature or fix branch from main.
2. Follow the naming conventions in the engineering handbook.
3. Keep changes focused and documented.
4. Open a pull request with a clear description and testing details.

## Standards

- Use meaningful commit messages.
- Keep the codebase clean and modular.
- Avoid committing generated files or secrets.
- Ensure tests and builds remain passing.
