# Volt Rental

Volt Rental is a smart bike rental platform built as a full-stack monorepo with a Spring Boot backend, a legacy frontend, and a modern React frontend.

## Repository Goals

- Deliver a production-ready bike rental experience
- Keep the architecture modular and maintainable
- Follow enterprise engineering practices
- Support future expansion into analytics, mobile, and fleet management

## Project Structure

- backend: Spring Boot REST API and business logic
- frontend: legacy web experience
- frontend-react: modern React client
- docs: engineering handbook and documentation
